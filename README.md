# Chance IT Studio Portfolio

Personal developer portfolio and business site for Chance IT Studio.

## What it does

A single-page site built around a scrollable "wheel" of sections (hero, about, work, services, process, contact). It showcases projects (TCMVP, SmokeSignal, GlovesOn, TTDice), lists services offered, explains the project process, and includes a working contact form. A small blog lives at /blog for SEO content. The page also carries full SEO metadata (Open Graph, Twitter cards, schema.org JSON-LD), a robots.txt, and a sitemap.xml.

## Tech stack

- Vanilla HTML, CSS, JavaScript (no framework, no build step)
- Google Fonts (DM Mono, Bebas Neue, Syne)
- Web3Forms for the contact form
- Schema.org structured data for SEO
